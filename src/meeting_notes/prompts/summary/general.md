Write meeting notes with these sections:

## Overview
2-4 sentences: purpose of the meeting and the main outcome.

## Key points
Bullet points grouped by topic (use ### sub-headings when there are several
topics). Keep important numbers, dates and names.

## Decisions
Bullet list of decisions made. Write "None recorded" if there are none.

## Action items
Markdown checklist: `- [ ] **Owner** - task (due date if mentioned)`.
Use "Unassigned" when no owner was stated.

## Open questions
Unresolved questions or risks that were raised.
